# Specifikacija za kontrolnu tačku 1

Cilj: dostaviti minimalan funkcionalni demo koji pokazuje osnovne zahteve iz zadatka.

Funkcionalnosti (minimum):
1. Endpoint za listu turističkih atrakcija (GET /api/attractions).
2. Endpoint za detalje atrakcije po ID-u (GET /api/attractions/{id}).
3. Podaci su dostupni kroz sample JSON (`data/sample-data.json`).

Nefunkcionalno:
- Kratko uputstvo za pokretanje u `backend/README-backend.md`.
- Bar jedan dijagram toka u `design/`.
- API specifikacija u `api/openapi.yaml`.

Deliverable za checkpoint 1:
- Radni backend skeleton + sample podaci.
- `docs/spec.md`, `design/` dijagrami, i `api/openapi.yaml`.
- Kratak `deliverables/checkpoint1-report.md` sa opisom šta je urađeno.
