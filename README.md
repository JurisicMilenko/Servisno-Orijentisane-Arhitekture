## Turistička aplikacija — Kontrolna tačka 1

Ovo je repozitorijum za projekat "Turistička aplikacija".

Cilj prve kontrolne tačke:
- Napraviti minimalnu strukturu repozitorijuma.
- Implementirati skeleton backend servera sa jednim ili dva endpoint-a koji vraćaju sample podatke.
- Pripremiti osnovnu dokumentaciju i API specifikaciju.

Članovi tima i uloge (predlog):
- Član A: `docs/` i `deliverables/`
- Član B: `design/` i dijagrami
- Član C: `backend/`
- Član D: `frontend/` i `README`

Kako pokrenuti (backend demo):
1. `cd backend`
2. `npm install`
3. `npm start`

Vidi `docs/spec.md` za listu funkcionalnosti za ovu kontrolnu tačku.
